# Kalyan-VLM: Humanitarian Emergency AI Agent 🩺🌍

**Kalyan-VLM** (VLM: Vision-Language Model) is a local-first, privacy-focused AI tool designed to assist first responders and individuals in emergency situations. 

### 🚀 Key Features
* **AI Vision (Local):** Uses the **Moondream** VLM via Ollama to analyze images of injuries or hazards instantly.
* **Privacy-First:** Processes all data on the local machine—no sensitive medical images are sent to the cloud.
* **RAG Integration:** Connects vision analysis with a local medical knowledge base for actionable triage steps.
* **Zero Cost:** Runs entirely on consumer hardware (MacBook Air) without expensive API fees.

### 🛠️ Tech Stack
* **Frontend:** React.js
* **Backend:** FastAPI (Python)
* **AI Engine:** Ollama + Moondream
* **Infrastructure:** Uvicorn

### 📈 Mission
Developed as a first-year BCA project to bridge the gap between advanced AI technology and community well-being (Kalyan).
